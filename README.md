# État antérieur à la refonte

Cette branche conserve le prototype fonctionnel du 14 novembre 2026 : sources, tests, références numériques et documentation historique. Les sauvegardes locales, profils et captures générés ne sont pas versionnés.

Ouvrir `comparison.html` via un serveur HTTP local. Les tests numériques s'exécutent avec Node.js ; les tests navigateur utilisent `test-gpu-runner.cjs` et un navigateur Chromium avec WebGPU.

La refonte est développée sur `main`. Cette branche sert de référence de comportement et de retour arrière.
